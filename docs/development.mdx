This page is for people who edit the Skylos docs. The site is built with
[Docusaurus](https://docusaurus.io/).

:::info
  **Prerequisites**:
  - Node.js 20 or newer
  - A clone of the `skylos-docs` repository
:::

### 1. Install dependencies

From the repository root:

```bash
npm install
```

The repository has no committed `package-lock.json`, so `npm ci` does not work.

### 2. Preview locally

```bash
npm start
```

A local preview opens at `http://localhost:3000`. It reloads when you save a
page.

To use another port:

```bash
npm start -- --port 3333
```

### 3. Build before you open a pull request

```bash
npm run build
```

The build warns about broken internal links and anchors. Fix every warning before you
push.

To check the built site:

```bash
npm run serve
```

## Where things live

| Path | What it holds |
|:---|:---|
| `docs/` | The pages, as `.mdx` files |
| `sidebars.ts` | The sidebar order |
| `docusaurus.config.ts` | Site settings, navbar and footer |
| `static/` | Images and other files served as-is |

## Writing style

- Short sentences and plain words.
- One idea per paragraph.
- Put every command in a code block.
- Check commands and flags against `skylos <command> --help` before you
  document them.

## Troubleshooting

  <details>
<summary>The build says a link is broken</summary>

    Docusaurus checks every internal link and anchor and prints a warning. Open the page it names,
    fix the path or heading, and run `npm run build` again.
  </details>

  <details>
<summary>The preview shows old content</summary>

    Clear the cache and start again:

    ```bash
    npm run clear
    npm start
    ```
  </details>
