The Skylos CLI is free and needs no account. Billing applies only to Skylos Cloud.
Skylos sells one-time credit packs: no subscriptions and no seats.

## Your first workspace

Your first workspace starts with a 7-day Workspace trial and 50 credits. The grant is once per
account; later workspaces start on Free with no credits.

Buying any credit pack turns on Workspace. Workspace then stays on for good: there are no seats
or subscriptions, and later packs only add credits. Credits never expire.

## What never uses credits

- Local CLI scans, with every analyzer and output format.
- Scan uploads, PR checks and the merge gate.
- MCP `analyze` without an API key, limited to five calls per rolling 24-hour window.

MCP tools run locally, but authenticated calls use Skylos Cloud for authorization and credit
deduction. A free API key does not make every MCP scan credit-free. See [MCP Server](/mcp-server).

## Refunds

Refunds are handled according to the checkout terms. A full refund removes that pack's credits.
Paid Workspace access remains while another completed credit-pack purchase exists. Refunding
the last paid pack can return the workspace to Free or its prior trial.

## Enterprise

Enterprise adds unlimited credits and the provenance audit, with higher project, history and API
limits. Contact `founder@skylos.dev`.

## Check your balance

```bash
skylos credits
```

`skylos credits` prints your workspace, plan and balance, the last five transactions, and a link
to buy more. It needs `skylos login` first. The Billing page in the dashboard shows the same
balance and history.

## At zero credits

Uploads, PR checks and local CLI scans keep working. Credit-priced MCP scans and other actions
that cost credits stop with
"Insufficient credits" and a link to Billing. For example, the MCP `remediate` tool returns:

```
Insufficient credits. Required: 10, available: 0.
Buy credits at https://skylos.dev/dashboard/billing
```

## FAQ

**Do credits expire?**
No.

**Does Workspace expire?**
Not after a purchase. The 7-day trial on your first workspace ends after 7 days unless you buy a
pack. After a purchase, Workspace has no time limit. Refunding the last paid pack can remove
paid access; another completed pack keeps it on.

**Can Free workspaces retain credits?**
Yes. Unused trial credits remain after the trial ends and can pay for credit-priced MCP calls.
Buying any new pack enables Workspace.

**Do scan uploads cost credits?**
No. Uploads, PR checks and the merge gate never use credits.

**What is the difference between plan-gated and credit-gated?**
Workspace features such as overrides, SARIF, inline PR comments, integrations and full trends
need the Workspace plan but use no credits. Actions in the credits table above use credits, and
comparing scans, AI triage and AI fix PRs also need Workspace.
