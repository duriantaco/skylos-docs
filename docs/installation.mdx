## Prerequisites

* Python 3.10+
* `pip` or `uv`

## Install

<Tabs>
  <TabItem value="pip" label="pip" default>
```bash
pip install skylos
```

  </TabItem>
  <TabItem value="uv" label="uv">
```bash
uv pip install skylos
```

  </TabItem>
</Tabs>

Optional extras add features that need extra packages:

| Extra | Adds | Install |
|-------|------|---------|
| `llm` | `skylos agent ...` LLM workflows and `--verify-security` | `pip install "skylos[llm]"` |
| `lint` | Ruff, for `skylos lint` | `pip install "skylos[lint]"` |
| `verdict` | Signature checks for `skylos verify-verdict` | `pip install "skylos[verdict]"` |
| `dart` | Dart parsing (compiles C, so it needs a C compiler) | `pip install "skylos[dart]"` |
| `test` | pytest, for `--trace` and fixture checks | `pip install "skylos[test]"` |
| `all` | Every extra above | `pip install "skylos[all]"` |

LLM features also need a model-provider key or a local model. See
[AI Features](./ai-features#setup).

## Container Image

Skylos publishes a first-party multi-arch CLI image to GHCR:

```bash
docker pull ghcr.io/duriantaco/skylos:latest
```

Run a scan against the current repository:

```bash
docker run --rm \
  -v "$PWD":/work \
  -w /work \
  ghcr.io/duriantaco/skylos:latest \
  . --json --no-provenance
```

For CI, prefer a pinned release tag instead of `latest`.

The image includes the Go engine and Dart support. It does not include the
`llm` extra.

## Initialization

Run the init command to create a default configuration in your project root.
```bash 
skylos init
```

This will create or append to your `pyproject.toml` file.

## Configuration

Skylos uses standard `pyproject.toml` configuration. You can tune complexity thresholds and ignore specific rules.
```toml
[tool.skylos]
# Analysis Settings
complexity = 15  # Max Cyclomatic complexity (Default: 10)
nesting = 5  # Max indentation depth (Default: 3)
max_args = 5  # Max arguments per function
max_lines = 100  # Max lines per function
ignore = ["SKY-L002"] # List of Rule IDs to ignore

# Gatekeeper Settings (skylos --gate)
[tool.skylos.gate]
max_security = 0  # Default: 10
max_quality = 10
strict = false  # Set true to disable interactive bypass in CI
```

Any critical finding or secret always fails the gate. You cannot turn that off
in config.

## Verify Installation

Check the version, then check the install and optional engines:

```bash
skylos --version
skylos doctor
```

`skylos doctor` checks Python, the Go engine, Dart support, ripgrep, config
files, CI setup and agent hooks.
