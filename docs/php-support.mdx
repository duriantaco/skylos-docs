---
title: "PHP Support"
description: "PHP dead code and selected security analysis support in Skylos."
---

Skylos analyzes PHP source with tree-sitter parsing for dead code and selected
security checks.

## File Coverage

| Area | Support |
|:---|:---|
| Extensions | `.php`, plus Drupal `.module`, `.install`, `.inc`, `.theme`, `.profile`, `.engine`; Blade templates (`.blade.php`) are read for references |
| Dead code | Classes, interfaces, traits, enums, functions, methods, constants, properties, imports, and includes |
| Security | Selected request-input checks: SQL injection, filesystem/include paths, unsafe deserialization, and Drupal markup and inline Twig templates |
| Quality | No dedicated PHP quality rules yet |

## Dead Code Detection

PHP analysis understands namespaces, class-like declarations, functions,
methods, constants, properties, `use` imports, and literal include paths.

Skylos treats PHP magic methods and PHPUnit lifecycle methods as framework or
runtime entrypoints:

- `__construct`, `__destruct`, `__invoke`, `__get`, `__set`, `__call`, and related magic methods
- `setUp`, `tearDown`, `setUpBeforeClass`, and `tearDownAfterClass`
- `test*` methods in PHPUnit-style test files or classes extending `TestCase`
- Laravel and Drupal conventions, such as routes, controllers and Drupal hooks

## Security Scope

PHP security checks track request-controlled values from superglobals such as
`$_GET`, `$_POST`, `$_REQUEST`, `$_COOKIE`, `$_FILES`, and `filter_input()` into
selected sinks:

- `unserialize()`
- file APIs such as `file_get_contents`, `file_put_contents`, `fopen`, `readfile`, `unlink`, `copy`, and `rename`
- `include`, `include_once`, `require`, and `require_once`
- SQL strings built from request input (`SKY-D211`), including Drupal request and Form API input
- Drupal `Markup::create()` with request data (`SKY-D226`) and request data compiled as an inline Twig template (`SKY-D349`)

```bash
skylos . --danger
```

## Limitations

Skylos does not currently run PHP type checking, Composer autoload resolution,
or dedicated PHP complexity rules. Secret scanning reads `.php` files only, not
the Drupal extensions. PHP has no inline suppression comment, and dependency CVE
scanning does not read `composer.lock`. Use PHPStan, Psalm, or the PHP runtime test
suite alongside Skylos when you need compiler-like validation.
