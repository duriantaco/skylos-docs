---
title: "Kotlin Support"
description: "Kotlin dead code and secret scanning support in Skylos."
---

Skylos provides a thin Kotlin scanner for dead-code detection and shared secret
scanning. It is designed to make Kotlin files visible to the normal Skylos
workflow without requiring Gradle, the Kotlin compiler, or Android build tools.

## File Coverage

| Area | Support |
|:---|:---|
| Extensions | `.kt`, `.kts` |
| Dead code | `private` classes, objects, interfaces, functions and methods, plus unused imports |
| Security | Secret scanning only (`--secrets`); no Kotlin security rules |
| Quality | No dedicated Kotlin quality rules yet |

## Dead Code Detection

Skylos reports only two kinds of Kotlin dead code:

- `private` declarations with no reference in the file
- unused imports

Any declaration without `private` (public, internal or protected) is treated as
used, because code outside the file may call it. So an unused public Kotlin
function is never reported.

To find references, Kotlin analysis reads these declarations and uses:

- top-level functions
- class, object, interface, and enum class declarations
- member functions
- imports and aliased imports
- direct calls and constructor-style calls
- annotation references

Skylos treats common framework-managed Kotlin entrypoints as live, including:

- `main`
- JUnit-style `@Test`
- Kotlin/Java override hooks such as `@Override`
- Compose `@Composable`
- selected Spring-style annotations such as `@Controller`, `@RestController`,
  `@GetMapping`, `@PostMapping`, and `@Bean`
- common Android lifecycle methods such as `onCreate`, `onStart`, `onResume`,
  `onPause`, `onStop`, `onDestroy`, `onCreateView`, and `onViewCreated`

```bash
skylos .
```

Example output:

```text
Main.kt:2  SKY-U001  unused function: unusedPriv
Main.kt:1  SKY-U002  unused import: UUID
```

## Secret Scanning

Kotlin files participate in Skylos secret scanning. Hardcoded provider tokens
and generic high-entropy credentials in `.kt` and `.kts` files are reported
through the same secrets engine used for other source languages.

```bash
skylos . --secrets
```

## Limitations

Kotlin support is intentionally thin today. Skylos does not run Gradle, the
Kotlin compiler, Android build tooling, or Kotlin type resolution. It reports
only `private` dead code and imports. It has no Kotlin command, SQL, SSRF,
filesystem, or quality rules. Kotlin has no inline suppression comment; use
`[tool.skylos] ignore`, `skylos whitelist`, or a baseline. Use Kotlin compiler checks, Android lint, Detekt, and project tests
alongside Skylos.
