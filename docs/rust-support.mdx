---
title: "Rust Support"
description: "Rust dead code and selected security analysis support in Skylos."
---

Skylos analyzes Rust source with tree-sitter parsing for dead code and selected
security checks.

## File Coverage

| Area | Support |
|:---|:---|
| Extensions | `.rs` |
| Dead code | Modules, structs, enums, traits, type aliases, functions, methods, fields, and imports |
| Security | Partial, with checks for selected web, database, filesystem and cryptographic APIs |
| Quality | Unreachable statements and duplicate branch bodies |

## Dead Code Detection

Rust analysis understands module paths, `use` imports, public items, `impl`
blocks, trait methods, derived behavior, test functions, and common implicit
methods such as `clone`, `default`, `drop`, `fmt`, `from`, `into`, `poll`, and
`call`.

Skylos treats `main`, test functions, and methods implied by common traits more
conservatively than ordinary private helpers.

## Security Scope

The development version recognizes these Rust APIs and data flows:

- Request text used as SQL in an executed rusqlite, SQLx, MySQL or MySQL async query. Fixed query text with separately bound request values stays quiet.
- Input reaching commands, filesystem paths, HTML output and the destination of a dispatched `reqwest` request.
- Certificate and hostname verification disabled by supported TLS APIs, plus sensitive session cookies issued without the Secure flag.
- HTTP authentication sent to a cleartext destination and exposed secrets put in request URLs, including HTTPS URLs.
- Exposed `secrecy::SecretString` values in logs and password writes, weak ciphers and hashes in supported crypto APIs, and fixed symmetric keys.
- Decoded request text in plain log messages, unescaped request fragments used in regexes, and selected unbounded allocation or JSON input paths.

Findings depend on the crate, the resolved API and the data path. For example, an async SQLx query usually has to be polled before Skylos reports its SQL text. DNS resolution, arbitrary macros and general cross-crate data flow remain gaps.

```bash
skylos . --danger
```

## Limitations

Skylos does not run `rustc`, Cargo resolution, borrow checking, or Rust type
checking. Pair Skylos with `cargo check`, `cargo clippy`, and tests for full
Rust validation.
